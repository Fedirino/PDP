# PDP — Produce Department Portal

Offline-first mobile tools for produce department operations.

## Hosting

### GitHub Pages
1. Create a new repo (e.g. `PDP` or `produce-portal`)
2. Upload all files from this folder to the repo root
3. Go to **Settings → Pages → Source** → select `main` branch, `/ (root)`
4. Site will be live at `https://fedirino.github.io/PDP/`

### Netlify
1. Go to [app.netlify.com](https://app.netlify.com)
2. Drag and drop this entire folder onto the deploy area
3. Site deploys instantly with a random URL
4. Optional: set a custom domain under **Domain management**
